# 🐱 dsh-companion-cat · DSH 陪伴小猫

> **请选择你的小猫！** 在 DeepSeek Harness 里，养一只会呼吸、会撒娇、会陪你看代码的小猫。

一只住在你代码编辑器里的小猫。它会呼吸、会伸懒腰、会在深夜提醒你睡觉、会在你烦躁时跳个舞逗你开心。**全程零 token 消耗**——所有反应都在你的浏览器里本地完成，不经过模型。

---

## ✨ 它有什么本事

### 🐾 多只小猫 · 请选择你的小猫
内置多只不同花色的小猫（橘橘 🍊 / 奶白 🤍 / 灰灰 🌫️），点一下"换一只"：
- **幕布选猫**：像抽卡一样，舞台幕布拉开，一排小猫头像牌，鼠标滑过金色高亮，点选确定
- 选中的猫会出现在界面右下角，**可以给它取个名字**（名字贴在猫脚下）
- 换猫时连气泡颜色都会跟着它的毛色变

### 🎬 会表演的小猫
- **点击小猫** → 随机施展一个技能（开心跳、伸懒腰、惊吓、打盹……）
- **左上角 ✦** → 打开技能菜单，选它表演什么
- 每 10-15 分钟它自己也会伸个懒腰/打个盹，有生活节奏
- 拖动小猫可以放到屏幕任何位置

### 🌲 森林主题 · 融入背景
- 提供**白天 / 黑夜 / 自适应**三种背景模式（自适应 = 动态视频，随时间变化）
- 透明度滑条调节背景蒙版，**文字永远清晰**（消息气泡、输入框、审批弹窗自动保持可读）
- 消息气泡、输入框都有木质/暖色边框，跟森林场景呼应

### 💬 会关心你的小猫
- **深夜提醒**：23 点后还在忙？猫会打盹并提醒你早点休息（每天一次，不烦人）
- **情绪感知**：输入框里出现"烦死了 / 气死 / 崩溃" → 猫先吓一跳，再跳个舞安慰你
- 输入"开心 / 太棒" → 猫跟你一起开心

## 🧠 原理：为什么零 token

插件分两半，跑在**你的浏览器**里：

| 半 | 文件 | 职责 | token |
|---|---|---|---|
| node 半 | `lib/index.js` | 静态资源路由 | 不调用 LLM |
| browser 半 | `lib/client.js` | 小猫 UI + 全部交互逻辑 | 不调用 LLM |

所有行为（时间判断、正则、点击事件、localStorage）都是**本地规则**，完全不经过模型请求。陪伴是免费的 💸

## 📦 安装

```bash
# 在 profile 目录下安装
dsh plugin --profile web add dsh-companion-cat
```

或者在 `$DSH_HOME/profiles/web/cordis.patch.yml` 中加入：

```yaml
- insert:
    - id: companion-cat
      name: dsh-companion-cat
```

重启 `dsh web`，刷新页面，小猫就来了。

## 🗂️ 项目结构

```
dsh-companion-cat/
├── package.json          # dsh.client 声明（platform: web）
├── assets/
│   ├── background-day.png    # 白天背景
│   ├── background-night.png  # 夜晚背景
│   ├── background-live.mp4   # 自适应动态背景（8s = 一天）
│   └── cats/                 # 每只猫一个文件夹
│       ├── orange/           # 🍊 橘橘（全套动作）
│       ├── white/            # 🤍 奶白
│       └── gray/             # 🌫️ 灰灰
└── lib/
    ├── index.js          # node 半：静态资源路由
    └── client.js         # 浏览器半：小猫本体
```

**想加一只新猫？** 把它的透明 GIF 放进 `assets/cats/<name>/`（命名 `idle.gif`、`happy.gif`…），再在 `lib/client.js` 的 `CATS` 表里加一行即可。
